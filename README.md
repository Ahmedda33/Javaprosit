## ✨ Overview
This project is part of a series of **Java exercises** focusing on **object-oriented programming** and **data structures**.  

It demonstrates:  
- Creating **classes and objects**  
- Using **attributes, methods, and constructors**  
- Working with **Java collections** (`ArrayList`, `HashSet`, `HashMap`, `TreeMap`)  
- Assigning objects dynamically and performing **sorting/searching**  

> Previously, a simpler project “Zoo” introduced OOP basics in Java.

---

## 🚀 Features
- Dynamic management of **employees and departments**  
- Assign employees to departments (one employee per department)  
- Display, search, and sort employees and departments  
- TreeMap sorting of employees by ID
